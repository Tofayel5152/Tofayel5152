## 🖥️ Running Locally

This is a static site with no build step required.

1. Clone the repo:
   ```bash
   git clone https://github.com/Tofayel5152/Tofayel5152.git
   ```
2. Open `index.html` in your browser, or serve it locally:
   ```bash
   npx serve .
   ```
